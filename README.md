# Belgrade.place
[belgrade.place](https://belgrade.place) is a website dedicated to learning about street names in city of Belgrade, Serbia 🇷🇸

This repository contains source code for the website.

## Developing
To run the project locally, you'll first need to install [bun package manager](https://bun.com).  

Once installed, you can run local development server:

```sh
bun run dev

# or start the server and open the app in a new browser tab
bun run dev -- --open
```

To create a production or preview version:

```sh
bun run build    #production build
bun run preview  #production preview build
```
